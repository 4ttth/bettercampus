BC BetterCampus Unofficial

A clearer HAU student portal, on your phone and laptop.

BetterCampus redesigns the Campus++ portal right in your browser. Same login, same data, same backend — just navigation that makes sense.

Install BetterCampus How to install Version 0.2.0

Install in 3 steps

  1. Install Tampermonkey for your browser (Chrome, Edge, Firefox, Safari or Brave) from tampermonkey.net.
  2. Come back here and press Install BetterCampus. Tampermonkey opens a page for it — press Install there.
    Install BetterCampus
  3. Open the HAU portal and sign in as usual.

On Chrome or Edge, Tampermonkey may ask you to switch on Allow User Scripts (or Developer mode) for it the first time. It shows a link to the exact setting.

  1. Install Firefox from the Play Store. Chrome for Android can’t run add-ons.
  2. In Firefox, add Tampermonkey, then open this page in Firefox and tap Install BetterCampus → Install.
    Install BetterCampus
  3. Open the HAU portal in Firefox and sign in.
  1. Install the free Userscripts app, open it once, and follow its setup.
  2. Go to Settings → Apps → Safari → Extensions → Userscripts, turn it on, and allow it on hau.campus-erp.com (or all websites).
  3. Open this page in Safari, tap Install BetterCampus, then tap the Userscripts icon in the address bar and choose Install.
    Install BetterCampus

After that, just open the HAU portal in Safari and sign in.

What changes

Four clear sections

Home, Academics, Finances and Me — instead of eight menus with duplicates like “Utilities” and “Account” both changing your password.

Home that answers you

Your next class, balance, latest grades and school notices on one screen.

Built for phones too

Bottom navigation on phones, a side rail on laptops, big tap targets, and dark mode.

Nothing new to learn

Payments, enrollment and evaluations still use the portal’s own forms — just in the new layout.

Good to know

It’s unofficial
BetterCampus is a student project. It is not made, endorsed or supported by Holy Angel University. For portal problems, contact the university as usual.
Your data stays on your device
It only runs on hau.campus-erp.com, never sees your password, and sends nothing anywhere. It reads the same portal pages you already can, and only to display them.
One login at a time
The portal itself signs you out elsewhere when you log in on another device. If that happens, BetterCampus shows a “Session ended” screen — just sign in again.
Turning it off
Use Me → Switch to classic portal, or Classic view on the login page. To remove it, delete BetterCampus in Tampermonkey or Userscripts.
Updates are automatic
Tampermonkey and Userscripts check this site for new versions, so you don’t need to reinstall.
